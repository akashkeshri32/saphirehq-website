- robots.txt: live at /robots.txt, allows all crawlers, points to the

  /domains/[slug]) — no change needed.
- Internal linking: nav + footer already link every major page; left

===============================================================
OPEN GRAPH / TWITTER IMAGE — for tomorrow
===============================================================
Once you have the 1200×630 branded image ready, no code changes are
needed — Next.js has a file-based convention for this:

- Save it as: app/opengraph-image.jpg (or .png)
  This becomes the default share image for every page site-wide.
- Optional, page-specific override: drop the same-named file inside
  a route folder, e.g. app/placement-statistics/opengraph-image.jpg,
  and that page will use it instead of the site-wide default.
- Next.js automatically generates all the og:image / twitter:image
  meta tags from the file — just drop it in the right folder and
  redeploy.

Everything else (og:title, og:description, twitter:card, site name,
locale) is already wired up per page, so the image is the only piece
left.
